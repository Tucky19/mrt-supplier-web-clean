# MRT Supplier — Public Decision Log

This public file records only non-sensitive technical and operating decisions.

Commercial decisions involving prices, costs, margins, stock, customers, suppliers, sales performance, campaign budgets, or internal targets are maintained in a private project-management record and must not be committed here.

## Central Project Manager workflow

MRT Supplier work is coordinated through a central PM workflow to reduce duplicate tasks across website, SEO, ads, content, CRM, product data, and sales operations.

## Public / private information boundary

Public GitHub:
- application code
- technical implementation notes
- pull requests and branches
- non-sensitive product data
- public-facing copy
- non-sensitive project status

Private PM record:
- pricing and cost
- margin
- stock levels
- customers and sales
- supplier terms
- budgets and campaign economics
- confidential strategy
